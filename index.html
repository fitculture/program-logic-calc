Master Logic Program & Plan Definitions

Program Tracks & Workout Structures

  • Plain Base & Maintenance 1x 15-min AM muscle session + PM cardio. Placed as a static day, not auto-filled to a burn goal. 0 protein shakes. Base loss goals above 2.0 lb per week are an unrealistic timeframe.
  • Base (Menopause, GLP-1, Lose Wt + Gain Muscle) 1x 15-min AM & 1x 15-min PM muscle sessions. Assigned when the user has 60 minutes or less. Fixed day rotation, not burn-goal auto-fill. 4 protein shakes. Loss above 2.0 lb per week is an unrealistic timeframe.
  • Accelerated (Menopause, GLP-1, Lose Wt + Gain Muscle) 1x 25-min AM & 1x 25-min PM muscle sessions (Metabolic Stack). Assigned when the user has more than 60 minutes. No 60-minute cap. Classes fill in order until the daily burn goal is met. 4 protein shakes.
  • Muscle Building & Athlete 1x 25-min AM & 1x 25-min PM muscle sessions. Athlete scales to burn goal; Muscle Building runs fixed rotation for surplus. 4 protein shakes + 1 extra main meal.

Meal Plan Tiers (Macros per Meal)

  • Plan A (3 Meals + 2 Snacks/day) Each meal: 21g Protein / 21g Carbs / 9g Fat (249 kcal). Standard Snack: 15g P / 15g C / 7g F (183 kcal).
  • Plan B (3 Meals + 2 Snacks/day) Each meal: 25g Protein / 25g Carbs / 11g Fat (299 kcal). Standard Snack: 15g P / 15g C / 7g F (183 kcal).
  • Plan C (3 Meals + 2 Snacks/day) Each meal: 30g Protein / 30g Carbs / 13g Fat (357 kcal). Standard Snack: 15g P / 15g C / 7g F (183 kcal).
  • Plan D (3 Meals + 2 Snacks/day) Each meal: 35g Protein / 35g Carbs / 15g Fat (415 kcal). Standard Snack: 15g P / 15g C / 7g F (183 kcal).
  • Plan E (3 Meals + 2 Snacks/day) Each meal: 42g Protein / 42g Carbs / 18g Fat (498 kcal). Standard Snack: 15g P / 15g C / 7g F (183 kcal).
  • Plan E + Extra Meal 4 Meals + 2 Snacks/day using Plan E macros. Exclusively assigned to Athlete and Muscle Building programs.

Protein Shakes & Usage

  • Shake Macro Target 21g Protein / 15g Carbs / 4g Fat (150 kcal) per shake.
  • 4 Shakes/Day Programs Menopause (Base & Accel), GLP-1 (Base & Accel), Lose Weight + Gain Muscle (Base & Accel), Athlete, Muscle Building. Placement: Scheduled strictly 1 before and 1 after the AM & PM muscle sessions.
  • 0 Shakes/Day Programs Plain Base and Maintenance.
